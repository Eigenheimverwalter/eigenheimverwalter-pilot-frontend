# Security Policy

Diese Anwendung verarbeitet perspektivisch sensible Kunden- und Immobiliendaten. Sicherheitslücken bitte vertraulich an den internen Eigenheimverwalter-Sicherheitskontakt melden. Vor einer öffentlichen Veröffentlichung muss hier die freigegebene Kontaktadresse ergänzt werden.

Keine echten Kunden-, Partner- oder Zugangsdaten in Issues, Logs oder Testdaten einstellen.
